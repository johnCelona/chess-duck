# ADR-0017 · Minigame tests: a sandbox apart from the Pond

Status: Accepted (John asked for it, 2026-11-23) · Source: `docs/design/05-minigame-tests.md`

## Context

John wants to play rough versions of many minigames before deciding what the real ones are, "without making design choices that are going to be locked in". The architecture rules still hold: no chess rules in a client, seeded results, no stored shape without a migration.

## Options

1. **Client-only prototypes** with a chess library in the browser. Quick, but breaks rule 2 and is thrown away for Unity.
2. **Full modes** with events, storage and lessons. Locks in exactly what is undecided.
3. **A server-side sandbox with one generic contract.** Each minigame is a pure state machine; one client screen draws them all.

## Decision

Option 3.

- **Domain:** `domain/minigames/`. A `Minigame` takes a seed and actions and returns a `Snapshot`: board, marks, arrows, buttons, animation frames and which inputs are open. Same seed and actions, same snapshots.
- **Service:** `services/minigames.py` keeps the latest 50 runs in memory. **Nothing is stored and no duck changes**: no XP, no events, no migration. A restart loses runs, on purpose.
- **Time:** the timed games follow ADR-0015: the service measures the player's time and passes it in as data.
- **API:** `GET /minigames`, `POST /minigame-runs`, `POST /minigame-runs/{id}/actions`, tagged experimental. They may change or disappear without a new API version, an exception to ADR-0002 limited to these three paths.
- **Content:** `domain/minigames/content.py` is generated by `scripts/build_minigame_content.py` from our own engine games, with answer keys. No third-party puzzles, so no license question, and neither play nor CI needs an engine.

## Consequences

- Adding a minigame is one Python file plus a line in `catalog.py`; the client does not change.
- Promoting one to the Pond means designing its real rewards, events and storage then. Its rules can be kept.
- The generic screen cannot show a game's own character. That belongs to the official version.

## Not building yet

Duck rewards, saved scores, the player's own duck answering puzzles, real-engine opponents, sound and art.
